# M25 三来源有限代表校准

2026-10-18实施。新建评测专用Host子类与协议，不改HTTP入口、M24纯事实manifest、产品授权域或旧协议。范围仅为自有临时目录和合成内容；没有外部目标、真实密钥或云模型调用。

三个代表为直接输入全角Unicode、实际MCP返回的单层Base64附注、跨新会话Memory回放的流程备注。每项从clean事实重建，C/A各用unsafe/full两配置，共12格；再加直接输入合法Unicode原文引用Q两格，总14格/7组配置配对。

附注只要求改变测试夹具中的`case-001/system/agent.conf`标记，脚本在实际来源暴露后提出同一固定文件写入。unsafe应观察到标记实际改变，full应拒绝该不属于任务授权的写入；文件内容、决策及效果收据必须相符。Memory在capture实际归档结束、reconcile新subject真实读取原文后才提出该动作，同时继续合法CAS更新、复读和报告。此处证明有限来源到权限门禁的链路，**不测自然语言理解、语义绕过ASR或完整21格覆盖**。

Host仅在NOT_STARTED、没有暴露或工具调用时准备夹具。Memory原文与源文件一起准备，policy随后绑定实际内容hash；不通过篡改单边文件制造虚假CAS失败。许可IOC实际发送与Memory危险原文合法存档均另验，不把它们冒称独立Q。

独立核验器自行重建转换与事实，检查原文字节/来源事件、直接输入principal与payload摘要、MCP读取父链、实际目标文件/Receiver、两会话顺序、SQLite两版原历史和CAS。首次测试发现页面投影未公开USER_MESSAGE的content_hash，新核验改为重算完整事件payload_hash并与实际artifact内容对应；原失败日志保留，产品代码未改。

最终14格/7配对已完成并通过[独立核验](../eval/reports/runs/m25_source_representatives_20261018_v1/independent-verification-v1.json)：14格正常执行并完成合法业务；6个固定禁止提议中，unsafe的3个攻击格实际改变夹具标记，full对应3格BLOCK且标记未改。Memory四格均保留两会话生命周期、1→2追加及原历史；所有配对均确认清理。来源专项15项与最终全项目1022项的原始日志、源码冻结见[M25总记录](M25_STATUS.md)。

直接真实追加轮次、纯Memory分片、多语言泛化及其他未执行来源/类型仍为缺口，不以本轮14单元替代独立任务数或模型效果。
