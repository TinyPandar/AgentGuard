# DeepSeek 与聊天控制台进度

日期：2026-10-18；基于 main 的 `981d873`。本轮开发不改写M19/M20/M21历史实验成绩。

## 实现范围

- DeepSeek 官方Chat Completions适配；默认`deepseek-flash`、非思考模式、1024输出上限、60秒超时；保留百炼入口。使用`--provider deepseek`，可通过`--model`指定模型。密钥从`DEEPSEEK_API_KEY`加载后移除服务环境变量，由可信Provider保留。
- 聊天页预填任务，Enter发送，Shift+Enter换行，启动成功清空输入。BLOCK自动切到报告，允许手动往返。仅原`report`接口支持自定义补充消息，其他模板使用固定授权目标；网关、来源约束、共享预算和审批保持生效。
- 模板能力标签；告警摘要、中文记忆告警与步骤定位；直接来源与继承来源区分。检测器仅给整段粗粒度范围，不声称定位恶意句子或还原模型因果。
- 工具返回正常项折叠，字面来源关联到告警或被BLOCK的项标红展开，展示资源/原因/定位。参数校验拒绝也属于BLOCK，不能自动当作攻击拦截。
- 悬浮报告球：正常完成绿、检测/拒绝红、运行蓝、等待/未完成黄；数字仅统计检出数。右侧每个视图保留单一主滚动区域，输入框固定。

## 消息正文记录的数据处理变化

`ProtectedModel`在既有出口检查通过后记录角色和正文预览，每条最多12000字符；旧任务不补造正文。该记录不包含私有思维。请求摘要与来源映射仍针对原请求；工具参数在原字段映射和调用记录中核查。

**上下文API和任务导出现在含有检查通过的消息正文，可能包含INTERNAL证据和用户补充，不再只有哈希/长度。** 该预览不是通用脱敏器，不要公开真实业务导出。Provider密钥和受保护合成秘密继续受现有出口检查约束。此变更不签发权限、不修改M9冻结实现；原运行档案保留原版。
