# ADR 003 结构化工具返回的来源接入

日期：2026-10-19。状态：首批本地完整验收通过；远端跨平台Python CI待确认。

## 问题

旧网关只登记并扫描顶层字符串`data.content`，Host却把完整工具返回序列化交给模型。嵌套字段、数组与额外字段乃至字段名中的指令可能缺少对应来源和发现。模型请求的递归凭据出口检查已存在，但不替代这层来源登记与注入规则扫描。

## 决定

1. 对工具返回建立不可变JSON快照。枚举字符串值和对象字段名，保存字段路径、种类与序列化文本区间；拒绝非JSON值、无效UTF-8、NaN/Infinity以及超过字节/深度/节点/文本字段界限的结果。不得悄悄截断后仍声称完整扫描。
2. 保留现有顶层正文Artifact和来源ID，继续供IOC确定性脱敏、Memory原文和历史效果Oracle使用。每个结果另登记一份完整结构Artifact，而非为所有短字段创建独立Artifact；其权限保持DATA_ONLY和禁止授权/执行/传输。正文受限标签向完整结构传播，不自动对额外字段脱敏或赋予转发权限。
3. 顶层正文沿用原规则/Memory扫描；其余字符串值与字段名逐项扫描，避免正文发现重复计数。发现的原始区间指向结构快照中JSON编码字段的范围，不把解码后的偏移冒作原始偏移。规范化视图不修改原文。
4. 来源绑定元数据只公开摘要、字节数、编码区间和安全字段路径；未知字段名以哈希投影，不能借字段路径泄露原文。完整返回保存在受控Artifact中，不复制到公开事件投影。
5. ALLOW返回在交给Host前完成登记。ASK提交先保存返回证据，只有Host实际把已批准结果交给模型续跑时，调用`expose_committed_result`登记暴露；操作者单独执行commit不提前改变模型上下文。重复提交和重复暴露均不重复执行副作用。
6. 工具已执行但返回校验失败时，记录执行结果错误并丢弃未受检返回，不把它写成执行前BLOCK或“未发生副作用”。已批准操作仍消耗审批并保留终态错误，禁止因回执不合法而自动重试。原有执行结果UNKNOWN语义继续生效。
7. 原正文与完整结构同时参与策略和请求来源检查；向模型提供可引用/委派来源菜单时，同一文档优先列原正文ID，避免因补充表示重复派发资料。只有嵌套结构而没有顶层正文时，完整结构ID仍可选择。菜单去重不删除来源、不改变实际返回，也不扩大子权限。

## 界限

- 单结果最大262144 UTF-8字节，最大深度16、值节点4096、字符串字段256（包含字段名）。该限制不保证整段模型上下文一定能装入，模型入口仍执行原有总量检查。
- 覆盖受支持JSON结构的字符串和字段名；不处理图片/二进制/任意对象，不证明跨字段拼接指令、七类绕过或统一语义分类已经完成。
- 不更改Contract/Grant、DSL权限和M9冻结实现，不扩展真实外网或云调用，不把公共入口保护当成Full独有增益。
- 历史矩阵保留原源码和结果。增加完整结构来源后，不再允许测试依赖`next(iter(set))`来猜唯一正文；必须按来源ID或实际父链选择并验证。

## 验证

新增专项覆盖嵌套/数组/额外值/字段名、JSON转义区间、快照不可变性、各类界限、嵌套SECRET出口、Memory延迟指令、真实stdio MCP，以及批准回执的来源与防重放。既有文件/记忆跨会话来源恢复和审批绑定断言继续保留。进展见[首批记录](../M26_RESULT_SOURCE_STATUS.md)。
