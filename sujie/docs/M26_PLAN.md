# M25之后的实施计划

制定：2026-10-18。本文件为待执行计划，不代表云入口已开启或新实验已经完成。起点是[M25离线验收](M25_STATUS.md)与[整体评估](../../competition/docs/M25_AND_OVERALL_REPORT_2026-10-18.md)。M25原协议、输入、报告与冻结文件继续保留。

下一阶段的核心目标：在真实模型上检验完整配置相对强基线的安全收益、合法业务代价与机制贡献，形成可复现的参赛证据。研究实验与演示交付并行推进。

**按用户本轮五项完整赛题要求细化：**先补统一多源字段接入/完整调用证据、跨轮语义研判与独立动态风险，再补五类动作专项、真实多轮/检索Memory和七类绕过、调用DAG与角色时序图。真实模型协议与资源准备并行；不能仅扩大模型比较而遗漏核心能力。逐项源码依据和退出条件见[五能力缺口复核](../../competition/docs/FIVE_CAPABILITY_GAP_REVIEW_2026-10-18.md)。下表原有比较准入工作继续保留，并纳入这些能力补齐任务。

| 工作 | 交付物 | 退出条件 |

| 受限云执行入口 | 明确资源配置、全角色共享请求预算、用量记录、传输尝试/回执与票据绑定、未知用量停止规则 | 使用封闭HTTP先通过正常、失败、取消、预算与清理校准；未获资源准入时不能发云请求 |

沿用已固定的property-based-testing与variant-analysis方法，验证预算/序列化/角色链不变量和已确认缺陷的同类遗漏；不为增加工具数量安装无明确用途的skills。

预算准入应区分请求上限、供应商报告用量和费用限制。本地预留单位不能承诺计费token或账单上限；若所要求的上限无法可靠约束，该资源配置不得进入云执行。调用前再核对官方模型可用性、计费口径与可实施的限制。

## M26-B：资源明确后进行真实模型开发比较

需要用户提供仓库外现有凭据CSV路径、总请求上限及token/费用预算。只提供路径，不在聊天发送密钥正文。校准、失败和重试均计入授权总量。

先运行少量覆盖主调用、审批续跑、子Agent与Memory的校准，确认实际接口、合法任务运行、用量与回执能完整核验。校准独立报告，不混入主比较分母；发生实现修复时另立源码版本和输出。

随后在冻结版本上执行同事实开发比较，优先沿用六候选48个唯一单元的结构；实际规模在看结果前按资源准入决定。若采用已有48格输入，必须继续标明development-exposed。不按哪项更容易受攻击来删选任务，不只补跑有利结果。

本阶段交付逐格原始证据、独立重算、配置配对和失败分析。验收要求是预算与协议符合、记录完整且结论与实际观察一致；有不利结果仍须保留。

## M27：形成研究结论

1. 在正式测试前冻结独立任务定义、开发/测试隔离办法、重复规则与统计方案。新seed属于同任务家族的重复，不自动增加独立任务数。
2. 用留出任务评估完整配置、强静态基线及预选消融，同时报告合法业务、安全效果、信息保全、失败与调用代价。
3. 按任务家族处理相关性，报告整数分母、配对差异与适当的不确定性；已观察的正式结果不用于反复调参后继续称留出。
4. 来源约束或恢复机制若无可测增益，应如实报告，并据此改进实现或收窄贡献主张。

本阶段的退出条件是能回答：Full相对强静态基线增加了什么、哪些任务有效、付出多少代价、哪些情况仍失败。实验规模由资源和统计方案确定，不把内部任务数量设计当成官方新增要求。

## 并行完成性能、复现与参赛交付

- 验证当前版网关开销：记录环境、负载、样本数、冷/热状态、延迟分位和失败。模型/网络耗时与网关处理耗时分别报告。
- 在干净环境复现安装、运行和独立核验；明确Host/工具/角色的可信及隔离边界。M24同容器smoke不替代新版本完整隔离验收。
- 完成三段实际演示：IOC审批与发送、跨会话Memory事实更新、危险原文保全；每段包含证据入口和失败解释。
- 形成匿名报告、相关工作/创新性对照、程序与证据派生包、依赖/资产许可清单和复现说明；由队伍完成身份与最终提交核查。
