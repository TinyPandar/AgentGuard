# 演示视频脚本（提交件 7）

> 用途：答辩/网评演示录屏。**录制时务必遵守匿名要求**：画面中不得出现学校、院系、指导教师、个人姓名、桌面文件名、Git 远程地址中的个人信息。
> 总时长建议 5–8 分钟；分辨率 ≥1080p；终端字号 ≥16pt，浅色或深色主题均可，但需保证文字清晰。

## 0. 录制前准备

```sh
cd sujie
.venv/bin/python dev.py prepare-tokenizer   # 首次需要；离线可跳过，相关测试会标注跳过
.venv/bin/python dev.py check               # 可选：先确认环境正常（耗时较长）
```

准备一个干净的空目录与会话，关闭含个人信息的窗口（邮件、聊天、浏览器书签栏）。

## 1. 镜头一：定位与威胁（约 40 秒，可配旁白）

不敲命令，用一句话讲清：

> “大模型智能体已经能读写文件、访问网络、调用 MCP 工具。提示注入可以藏在外网页、邮件、MCP 工具描述和长期记忆里，诱导智能体用**自己合法的权限**去外发秘密、执行危险命令。溯界部署在宿主与工具之间，把‘模型提议’和‘实际授权’分开。”

## 2. 镜头二：确定性端到端演示（约 2 分钟）

```sh
cd sujie
.venv/bin/python dev.py demo
```

旁白要点（按输出顺序）：
1. 可信任务契约先冻结授权边界；
2. 不可信来源被**读取并分析**，但只能作为数据；
3. 三态决策：正常动作 ALLOW，越权动作 BLOCK，敏感动作 ASK；
4. 阻断返回**不含秘密**的结构化安全异常；
5. 智能体据此重新规划，原始业务仍然完成；
6. 全程 0 云调用。

## 3. 镜头三：操作台（约 2 分钟）

```sh
.venv/bin/python dev.py console
```

浏览器打开 `http://127.0.0.1:8765`，从 `.control-runtime/operator-token.txt` 复制操作者凭据登录。演示：

1. 发起一个包含注入载荷的研判任务；
2. 展开**攻击链视图**：来源 → 传播 → 提议 → 决策 → 效果；
3. 在待审项上演示 `批准不执行 / 提交才执行`；
4. 展示最终业务报告与“危险命令仅作为引用证据”。

> 注意：**不要录入任何真实凭据或真实业务数据**；演示使用合成秘密（honeytoken）。

## 4. 镜头四：可复算与证据（约 1 分钟）

```sh
.venv/bin/python dev.py eval-detection
.venv/bin/python eval/run_business_validation.py \
  --protocol-file eval/protocols/four_business_workflows_v2.json \
  --out-dir eval/reports/runs/demo
.venv/bin/python eval/verify_runtime_validation.py eval/reports/runs/demo
```

旁白要点：判定来自**真实副作用 Oracle**（Receiver 实际请求、文件内容、进程收据、Git 远端 ref、Memory 版本），不是模型自评；可由上述命令离线复算。

## 5. 镜头五：边界（约 30 秒，必须说）

- 本演示是**确定性脚本模型 + 0 云调用**；真实云模型为小样本结果，不作为比赛 ASR；
- `dev.py eval-detection` 是**规则检测器作用域**，不是端到端智能体成功率；
- 当前完成的完整拓扑**尚未在 Linux 环境做整体隔离与性能验收**。

## 6. 口播稿（可直接照读）

> 大家好，这是我们为题目五设计的作品——溯界，一个部署在大模型智能体宿主与 MCP/本地工具之间的运行时安全网关。
>
> 智能体的能力越强，攻击面越大。提示注入可以藏在网页、邮件、MCP 工具描述甚至长期记忆里，让智能体用自己合法的权限去做越权的事。溯界的设计原则是：**模型提议不等于授权**。我们用可信任务契约冻结授权边界，用来源—用途信封约束不可信内容只能被分析、不能被授权，再对真实工具动作做放行、确认或阻断，并在阻断后给出不含秘密的结构化异常，让智能体重新规划、继续完成原本的研判任务。
>
> 现在演示的是确定性脚本模型下的完整闭环：注入载荷被读入上下文、被分析，但它的越权指令被阻断，攻击链在操作台上完整可见，而业务报告依然生成。
>
> 与只看模型文本的方案不同，我们的判定来自真实副作用：封闭接收端的实际请求、文件内容、进程收据、Git 远端引用和记忆版本状态。这些结论都可以用仓库里的命令离线复算。
>
> 需要说明的是：本演示是确定性脚本模型、零云调用；真实云模型目前是小样本验证，我们不把它表述为比赛攻击成功率；规则检测器的作用域也不是端到端成功率；完整拓扑的 Linux 整体隔离与性能验收仍在进行中。谢谢观看。
